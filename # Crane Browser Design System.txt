# Crane Browser Design System

> Elegant. Fast. Calm.

The Crane identity is inspired by the Sandhill Crane in flight. It represents
clarity, freedom, intelligence, and effortless movement.

Unlike aggressive browser branding, Crane feels lightweight and premium.

---

# Brand Personality

- Calm
- Intelligent
- Fast
- Premium
- Minimal
- Modern
- Trustworthy

Imagine if Apple designed a web browser.

---

# Logo Philosophy

The logo is not flat.

Instead, the crane uses subtle depth through layered white tones.

The goal is to create an icon that feels alive while remaining extremely clean.

Never use harsh outlines.

The silhouette should always remain recognizable at 16px.

# Icon Style

Rounded square.

16% corner radius.

White Crane centered.

No gradients in background.

Background stays solid #0B1D36.

The bird may contain subtle shading.

Note: the 16% radius is scoped to the app icon only, where it is fixed by
platform icon masks (macOS, Windows, Android, iOS). It does not extend to
in-app UI — see Visual Direction and Interface Principles below.

---

# Visual Direction

Large amounts of negative space.

Very little decoration.

Large typography.

Square corners.

Thin borders.

No shadows.

Separation comes from value contrast and hairlines, never a curve or a
drop shadow.

Everything should feel effortless.

# Interface Principles

## Tabs

Square.

Sit flush against the deeper navy chrome behind them.

No shadows. The active tab is distinguished by lifting to the signature
Navy against the darker chrome — value contrast only, no elevation effects.

## Address Bar

Large.

Full-width square band, not an inset field.

Minimal chrome — no border on the input itself; the band it sits in
carries the only hairline.

## Sidebar

Dark navy.

Icons only.

Expands on hover.

# Don't

❌ Heavy outlines

❌ Bright gradients

❌ Any drop shadow, hard or soft

❌ Rounded corners in the UI chrome (tabs, address bar, buttons, panels)

❌ Pure black

❌ Skeuomorphism

❌ Excessive glass

---

# Do

✓ Soft white layering

✓ Lots of breathing room

✓ Navy backgrounds

✓ Thin borders

✓ Square corners

✓ Large whitespace

✓ Gentle motion

✓ Elegant proportions

---

# Favicon

16×16

Simplify wing feathers.

Remove fine feather detail.

Keep only:

- neck
- head
- wing silhouette
- tail

The favicon should still be recognizable instantly.

---

# Brand Statement

Crane is a browser designed to disappear.

The interface never competes with the web.

It simply carries you there with speed, elegance, and clarity.
